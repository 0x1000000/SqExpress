# Source assertion review

The live matrix proves the executed ports run successfully. This ledger separately tracks direct comparison of scenario inputs, queries, branches, and assertions against C#. A mapping marked `ported` is not by itself proof of that comparison. Driver representation adaptations belong in adapters; SQL semantics and exact values remain scenario assertions.

## Review coverage

All 47 source scenarios have been directly compared. The machine-readable source hashes, mappings, exclusions, dialect restrictions, and source-chain order are in scenario-inventory.json. Final acceptance also requires the current full library and live integration verification results; this ledger alone does not prove those results.
